# Icons

Equipment icons from [Tabler Icons](https://tabler.io/icons) 3.19.0, MIT license
(`LICENSE-tabler-icons.txt`): `wave-sine`, `cylinder`, `ball-volleyball`, `ball-basketball`,
`weight`, `barbell`. The `.svg` files are the source; the app loads the `.pdf` files made by
`swift scripts/convert-icons.swift`.
